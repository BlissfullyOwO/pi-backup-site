# Raspberry Pi Backup

A personal backup application for my Raspberry Pi 5.

This application uses Rclone and Restic to create encrypted backups of my Raspberry Pi files and system configurations, storing them securely in my personal Google Drive.

Google Drive access is used only to create, maintain, and restore my personal backups.

This application is intended for personal use and is not offered as a public service.
